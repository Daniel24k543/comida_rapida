# Mordisco (demo)

Página demo de comida rápida con el estilo "punk rojo vino": titulares gigantes, scroll con animaciones, menú en carrusel y una página por producto.

HTML, CSS y JavaScript puros, sin dependencias ni compilación.

## Ver la página

```bash
python -m http.server 8765
```

Luego abre <http://localhost:8765/>.

## Contenido

- `index.html`, `style.css`, `app.js`: la página.
- las fotos (.jpg y .png): fotos reales de Wikimedia Commons (dominio público o CC0).

## Créditos de las fotos

Wikimedia Commons, dominio público o CC0: Thiago Fior de Castro, Miansari66, Ridiculopathy, Jiafei Slay Queen, Andy Li y pic_p_ter.

## Aviso

Es una demo: el nombre, los precios, la dirección y las respuestas de ejemplo son ficticios.
